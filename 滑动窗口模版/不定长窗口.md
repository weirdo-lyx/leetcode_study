leetcode 3. 无重复字符的最长子串
给定一个字符串 s ，请你找出其中不含有重复字符的 最长 子串 的长度。

 

示例 1:

输入: s = "abcabcbb"
输出: 3 
解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        left = ans = 0
        cnt = defaultdict(int)
        for right in range(len(s)):
        
            while cnt[s[right]] > 1: //循环看是不是因为最左边导致的重复
                cnt[s[left]] -= 1
                left += 1   
            cnt[s[right]] += 1 //把字符加进来
            ans = max(right-left+1,ans) 
        return ans
```
不定长的核心思路就是这个while循环遍历看看左边是不是导致了条件不满足然后移动左指针。注意要先把字符加进来，而不是放在while下面

当然这道题可以简单点用set
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        seen = set()
        left = 0
        max_l = 0
        for i in range(len(s)):
            while s[i] in seen:
                seen.remove(s[left])
                left += 1
            max_l = max(max_l,i-left+1)
            seen.add(s[i])
        return max_l
```

提示
给你两个长度相同的字符串，s 和 t。

将 s 中的第 i 个字符变到 t 中的第 i 个字符需要 |s[i] - t[i]| 的开销（开销可能为 0），也就是两个字符的 ASCII 码值的差的绝对值。

用于变更字符串的最大预算是 maxCost。在转化字符串时，总开销应当小于等于该预算，这也意味着字符串的转化可能是不完全的。

如果你可以将 s 的子字符串转化为它在 t 中对应的子字符串，则返回可以转化的最大长度。

如果 s 中没有子字符串可以转化成 t 中对应的子字符串，则返回 0。

 

示例 1：

输入：s = "abcd", t = "bcdf", maxCost = 3
输出：3
解释：s 中的 "abc" 可以变为 "bcd"。开销为 3，所以最大长度为 3。
示例 2：

输入：s = "abcd", t = "cdef", maxCost = 3
输出：1
解释：s 中的任一字符要想变成 t 中对应的字符，其开销都是 2。因此，最大长度为 1。

```python
class Solution:
    def equalSubstring(self, s: str, t: str, maxCost: int) -> int:
        left = 0
        tempcost = 0
        ans = 0
        for i in range(len(s)):
            
            tempcost += abs(ord(s[i])-ord(t[i]))
            while tempcost > maxCost:
                tempcost -= abs(ord(s[left])-ord(t[left]))
                left += 1
            ans = max(ans,i-left+1)
        return ans
 ```

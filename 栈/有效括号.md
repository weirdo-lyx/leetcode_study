提示
给定一个只包括 '('，')'，'{'，'}'，'['，']' 的字符串 s ，判断字符串是否有效。

有效字符串需满足：

左括号必须用相同类型的右括号闭合。
左括号必须以正确的顺序闭合。
每个右括号都有一个对应的相同类型的左括号。
 

示例 1：

输入：s = "()"

输出：true

示例 2：

输入：s = "()[]{}"

输出：true

示例 3：

输入：s = "(]"

输出：false
```python
class Solution:
    def isValid(self, s: str) -> bool:
        stack = []
        for ch in s:
            if stack and ch == '}' and stack[-1] == '{':    
                stack.pop()
                continue
            if stack and ch == ']' and stack[-1] == '[':    
                stack.pop()
                continue
            if stack and ch == ')' and stack[-1] == '(':  
                stack.pop()
                continue
            stack.append(ch)
        return len(stack) == 0
```          
注意continue，消除了这个就不再加入了。
和之前思路一样，遍历字符串，取当前字符，然后看列表最后一个字符和这个能不能配对，如果能配对就pop掉。
